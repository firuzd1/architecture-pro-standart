### **Функциональные требования**

| **№** | **Действующие лица или системы** | **Use Case** | **Описание** |
| :-: | :- | :- | :- |
| 1 | Менеджер кол-центра, Система кол-центра | Просмотр актуальных ставок | Менеджер кол-центра открывает систему и видит актуальные ставки по депозитам для консультации клиентов |
| 2 | Партнёрский кол-центр | Получение ставок | Партнёрский кол-центр получает файл с актуальными ставками через SFTP раз в день |
| 3 | Бэк-офис депозитов, АБС | Обновление ставок | Менеджер бэк-офиса обновляет ставки в АБС вместо Excel-файла |
| 4 | АБС, Система кол-центра | Синхронизация ставок | АБС передаёт актуальные ставки в систему кол-центра |

### **Нефункциональные требования**

| **№** | **Требование** |
| :-: | :- |
| 1 | Ставки в системе кол-центра обновляются не реже одного раза в день |
| 2 | Партнёрский кол-центр получает файл через SFTP — API вызовы невозможны |
| 3 | Данные о ставках не должны содержать информацию о клиентах |
| 4 | Процесс передачи ставок должен работать автоматически без участия сотрудников |

### **Решение**

Ставки по депозитам переносятся из Excel в АБС. Бэк-офис депозитов управляет ставками в АБС. АБС раз в день выгружает актуальные ставки и передаёт их в систему кол-центра через API. Система кол-центра показывает ставки менеджерам.

Для партнёрского кол-центра АБС формирует файл со ставками и выгружает его через SFTP.

### **Список задач для каждой системы**

**АБС:**
- Добавить справочник ставок по депозитам
- Реализовать интерфейс для бэк-офиса депозитов для управления ставками
- Реализовать выгрузку ставок в систему кол-центра через API
- Реализовать формирование файла со ставками для SFTP

**Система кол-центра:**
- Добавить раздел с просмотром актуальных ставок
- Реализовать получение ставок из АБС через API

**Интеграция:**
- Настроить SFTP для передачи файлов партнёрскому кол-центру
- Настроить расписание выгрузки ставок раз в день

**Бэк-офис депозитов:**
- Обучить сотрудников работе со ставками в АБС вместо Excel

### **Альтернативы**

Оставить Excel и рассылать его по почте в кол-центр — отклонено, процесс ручной и ненадёжный, легко ошибиться.

Дать кол-центру прямой доступ к АБС — отклонено, требования безопасности запрещают давать доступ к АБС сторонним системам напрямую.

**Недостатки, ограничения, риски**

- Ставки обновляются раз в день — в течение дня данные могут быть неактуальными
- Партнёрский кол-центр работает только с файлами через SFTP — нет возможности получать ставки онлайн
- Перенос ставок из Excel в АБС требует участия команды АБС и согласования с бизнесом
