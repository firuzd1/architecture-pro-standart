### **Функциональные требования**

| **№** | **Действующие лица или системы** | **Use Case** | **Описание** |
| :-: | :- | :- | :- |
| 1 | Новый клиент, Сайт | Подача заявки на кредит с сайта | Клиент оставляет ФИО и телефон. Если заполняет паспортные данные — получает предварительное решение по кредиту сразу |
| 2 | Клиент, Интернет-банк | Просмотр предодобренного предложения | Клиент видит предодобренное предложение по кредиту если скоринг уже проводился |
| 3 | Клиент, Интернет-банк | Подача заявки на кредит | Клиент указывает счёт зачисления и данные заявки, подтверждает смс-кодом |
| 4 | Система скоринга, БКИ | Скоринг нового клиента | Для нового клиента скоринг проводится только по данным БКИ |
| 5 | Кредитный конвейер | Обработка заявки | Менеджер обрабатывает заявку в кредитном конвейере, по предодобренным — в тот же день |
| 6 | АБС, СМС-шлюз | Уведомление клиента | Клиент получает смс при изменении статуса заявки |
| 7 | Менеджер отделения, АБС | Продолжение заявки в отделении | Если клиент уже подал заявку онлайн — менеджер продолжает работу с той же заявкой |

### **Нефункциональные требования**

| **№** | **Требование** |
| :-: | :- |
| 1 | Заявки по предодобренным предложениям обрабатываются в тот же рабочий день |
| 2 | Систему скоринга нельзя нагружать дополнительными предрасчётами — высокая нагрузка в рабочие часы |
| 3 | Обмен между АБС и кредитным конвейером раз в сутки — не ускорить |
| 4 | Кредитный конвейер и система скоринга поддерживают горизонтальное масштабирование и работу 24/7 |
| 5 | Трафик шифруется через HTTPS/TLS |
| 6 | Новый клиент обязан прийти в отделение для идентификации и получения кредита |
| 7 | Доступность сервисов 99,9%, работа 24/7 |
| 8 | Заявка с сайта и из отделения — одна и та же заявка в системе |

### **Решение**

Для подачи заявки на кредит с сайта добавляется форма с ФИО, телефоном и паспортными данными. Если клиент заполнил паспортные данные — сайт через API обращается к системе скоринга используя только данные БКИ и возвращает предварительное решение. Заявка сохраняется в кредитном конвейере.

В интернет-банке добавляется модуль кредитов. Предодобренные предложения формируются заранее на основе скоринга. При подаче заявки она передаётся в АБС, оттуда раз в сутки попадает в кредитный конвейер. Для предодобренных заявок добавляется отдельная очередь с приоритетом — менеджеры обрабатывают их в первую очеред
